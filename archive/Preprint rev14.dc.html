01

Two ink families

Plates are printed with the page and behave like ink: full strength, structural, never translucent. Markers are added afterwards and behave like a highlighter: translucent, always a field behind type, never type itself. Nothing in the system may be both.

No fixed meanings. A plate is chosen by position and weight, the way a printer assigns a colour to a layer — so green is not “success” and red is not “error” unless the component says so in words too.

Plates are for fills, rules, large type and figure marks. Below 18px they hand over to their text-safe companions — --g-text, --r-text, --b-text — same hue, enough contrast to be read. A plate that has never been measured as 13px text is not a text colour.

markers · applied by handnever as text
{{ m.demo }} {{ m.name }}

The rule exists because the alternative fails: #dee e2e citron as text on eggshell measures about 1.6:1. As a field behind ink it measures 14:1. Same colour, opposite outcome.

Markers keep working in dark mode because the ink on top never changes — only the field's opacity drops.

And a marker is a painted box, so it stacks in source order. A line set with display leading can be overpainted by the field of the line beneath it — lift the ink above onto its own layer, never loosen the leading to compensate.

02

What carries the words

You asked whether there's science. Honestly: not the science people claim. The serif-versus-sans reading-speed studies mostly wash out at screen sizes — no reliable comprehension or speed difference has held up. What does hold up is measure, x-height, line spacing, and contrast.

  • Measure — 60–75 characters. Beyond that the eye loses the line return.
  • Leading — 1.55–1.7 at reading size. The single biggest lever.
  • Size — 17–19px body. 15px is the most common self-inflicted wound.
  • Contrast — near-black on eggshell, not grey on grey.
body face {{ faceNote }}

A design system is a claim about what will not change. The interesting part is never the components — it is the small number of things you are willing to keep doing when they are slightly inconvenient, and the even smaller number of moments where you break them on purpose and say so out loud.

Read three paragraphs at this size and you will know within a few seconds whether the face is doing its job. If a letterform starts to feel like a personality rather than a voice, it belongs in a heading instead of a body.

at 13px, same face

Small text is where a face fails first. Table cells, captions and footnotes are the honest test — anything with fussy detail turns to noise here.

italic & figures

An italic aside, then 0123456789 — and a citation1.

my recommendation

Keep Zilla Slab. It has a large x-height, low stroke contrast and flat serifs — the qualities that survive small sizes — and it is already yours. Switch only if it starts feeling like a costume.

On the reluctance of systems to break their own rules

Why consistency is cheap, why exceptions are expensive, and why a design system that has never violated itself has probably never been used for anything difficult.

rev 14 · 2026-07-26 §4 figures · 2 interactive
contents
{{ t.n }} {{ t.label }}

Every system I have written starts strict and ends apologetic. The strictness is easy: pick four radii, three faces, six slots, and refuse. What is hard is the third month, when a screen arrives that the system describes accurately and serves badly — and the honest move is to break something.

The reluctance is not aesthetic, it is administrative. A violation has to be explained to someone later, and explanation is expensive, so teams quietly prefer a page that is uniformly mediocre to one that is excellent with a footnote. This is the failure mode this system is built against.1

The proposal is administrative too: write the exceptions into the contract, give each one a budget, and mark them so nobody has to guess whether a deviation was intent or drift.2

1

Sidenotes sit in the margin at reading height instead of collapsing to the foot of the page. On narrow screens they fold inline, numbered, in source order.

2

A budget is not a limit on quality. It is a limit on how many things one screen is allowed to be about.

A budget, formally

Let v be the number of licensed violations visible in a single view, and w the weight a reader assigns to any one of them. Attention does not accumulate; it divides.

w(v) = 1v · wmax(1)

At v = 1 the exception carries its full weight. At v = 2 each carries half, which is worse than having none — the reader now has two candidates for “the important thing” and no way to choose. Hence law 00.

Implementation

The three press inks are assigned by position, not meaning. In code that means syntax colour comes from the plate set with no semantic claim attached:

exceptions.ts 
// one licence per view — law 00 is not advisory
export function grant(held: Licence[]) {
  if (held.length > 1) return { active: null, reason: 'cancelled' };
  return { active: held[0] ?? null, reason: 'in force' };
}
definition

Licensed breach. A deviation named in the contract, budgeted per view, and marked so that a reader can tell intent from drift. Anything unnamed is drift.

Law 00 — two breaches cancel

Not discouraged. Cancelled. Attention divides rather than accumulates, per equation (1).

A breach used twice is an undeclared token

The second appearance stops being a breach. Name it, give it a slot, write its states — or stop.

The law must survive the breach

If breaking it makes it look arbitrary, the law was wrong. Delete it instead of licensing around it.
