# UI kit — docs and dashboard

The second and third surfaces: a documentation page with a persistent nav, and a
data view. Same contract as the reader, harder geometry — a dashboard may run on
the `hard` end of the cut scale where a reading page sits mid-scale.

- `index.html` — click-through: switch between Docs and Dash.

## What changes from the reader

| | reader | docs / dash |
|---|---|---|
| column | 66ch, centred | 66ch beside a nav rail |
| density | one section per idea | uniform rows, tighter padding |
| plates | figures and registers | series position, status rows |
| marks | the reader's own layer | absent — nobody highlights a dashboard |
